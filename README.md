# 👥 KeenKeeper — Keep Your Friendships Alive

KeenKeeper is a friendship management web application that helps users maintain meaningful relationships by tracking interactions like calls, texts, and video chats. The app allows users to manage friendships, monitor communication goals, and visualize interaction analytics in a clean and responsive interface.

# 📌 Features

- Responsive Navbar with active route highlighting
- Beautiful Banner section with summary cards
- Dynamic friend cards with status-based styling
- Detailed Friend Profile page
- Quick Check-In system (Call, Text, Video)
- Automatic Timeline entry generation
- Toast notifications for interactions
- Timeline filtering by interaction type
- Friendship Analytics with Pie Chart
- Custom 404 Page
- Loading spinner while fetching data
- Fully responsive design for mobile, tablet, and desktop

# ⚡ Core Functionalities

## 👫 Friend Management
Users can view all friends in a responsive card layout with:
- Profile Picture
- Name
- Days Since Contact
- Tags
- Dynamic Status

## 👤 Friend Details
Each friend has a detailed page containing:
- Bio
- Email
- Relationship Goal
- Contact Statistics
- Action Buttons

## 📜 Timeline System
When users click:
- 📞 Call
- 💬 Text
- 🎥 Video

A new timeline entry is automatically added with:
- Current Date
- Interaction Type
- Friend Name

## 📊 Friendship Analytics
Pie chart visualization showing:
- Total Calls
- Total Texts
- Total Video Calls

# 📦 Installation

## Clone the repository

```bash
git clone https://github.com/your-username/keenkeeper.git
```

## Go to project directory

```bash
cd keenkeeper
```

## Install dependencies

```bash
npm install
```

## Run the development server

```bash
npm run dev
```
